# Projetos
Nosso projeto tinha como proposta inicial fazer um simples sistema de segurança com uma proposta relativamente entre aberta. Porém tivemos uma ideia mais elaborada, em vista que o exemplo que foi passado para a gente era sobre uma escola que sofreu um ataque de segurança. Nessa perspectiva, decidimos fazer um sistema escolar com o máximo de segurança possível nas condições do vscode, e usabilidade eficiente seguindo as demandas passadas pelos professores.

Inicialmente, o usuário pode optar por fazer o login como professor, estudante ou ADM, caso ele tente fazer isso fora do horário de funcionamento convencional do sistema o login é caracterizado como suspeito. Caso o usuário erre 3 vezes vezes a senha ele recebe um timeout para evitar invasão por tentativas de acesso consecutivas e o login é caracterizado como suspeito. Se o usuário errar 5 vezes a senha, é categorizada uma tentativa de invasão.

# Aluno:
No portal do aluno adicionamos opções que são demandas básicas do dia a dia, como consultar notas, faltas e os dados do aluno.

# Professor:
No portal do professor ele pode adicionar notas e faltas de algum estudante ao escrever os dois primeiros e dois últimos digitos do estudante, além de ser possível acessar matrícula ocultada do aluno.

# Administrador:
É o carro chefe do nosso projeto, ele tem diversas opções, como criar novos usuários(sendo estudantes, ADM's ou professores)  a senha(com 12 digitos) e a mátricula(com 10 digitos) é criada automaticamente para padronizar o tamanho e aumentar a segurança, consultar dados via código ou via IA, editar dados dos estudantes ou professores, excluir usuários, banir máquinas e consultar as máquinas banidas
